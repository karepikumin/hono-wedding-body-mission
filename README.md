# Wedding Body Mission v5

v5では、運動フォームが分かりやすいように、かわいい女性イラストの「FITNESS GUIDE」ポスターをアプリ内に追加しました。

- 10種目の一覧イラストを表示
- 各種目をタップすると個別の手順・ポイントも確認可能
- 達成スタンプ、連続記録、30日カレンダーなどv4の機能を継承
- データはlocalStorageに保存

GitHub Pagesでは、以下を同じ階層にアップロードしてください。
- index.html
- manifest.webmanifest
- fitness-guide.png
- icon-192.png
- icon-512.png
